# 场景 Preset 库（17 个）

> 每个 preset = 场景 + 方法论（内部使用，不暴露给用户）+ 抽取重点 + 专属模块模板。
> 所有 preset 共享**公共底座**（元信息 + 执行摘要 + 待办 3W），下面只写各自的"价值内核模块"。

---

## A 类：商务 / 销售全流程

### S1 需求分析 / 客户调研会
- **方法论**：BANT / MEDDIC + 5W1H
- **抽取重点**：客户现状、痛点、决策链、预算信号、时间节点
- **专属模块模板**：
  ```markdown
  ### 客户需求与现状
  - 现状（现在怎么做/用什么）：…
  - 核心痛点：…（按优先级）

  ### 决策链与预算（MEDDIC 视角，内部口径）
  | 维度 | 内容 |
  |---|---|
  | 关键指标(Metrics) | … |
  | 经济买家(谁批钱) | … |
  | 决策标准 | … |
  | 决策流程(直采/招标) | … |
  | 痛点(Pain) | … |
  | 内部支持者(Champion) | … |
  | 预算信号 | …（⚠️内部敏感，对外版剔除）|
  | 时间线 | … |
  ```

### S2 产品演示 / Demo 会
- **方法论**：反馈捕获 + 异议记录
- **抽取重点**：客户反馈、异议/顾虑、亮眼兴趣点、下一步
- **专属模块模板**：
  ```markdown
  ### 客户反馈
  - 正向反馈/兴趣点：…
  - 中性观察：…

  ### 异议与顾虑（逐条跟踪）
  | 客户顾虑 | 当场回应 | 是否解决 | 后续动作 |
  |---|---|---|---|
  | … | … | 是/否/待跟进 | … |

  ### 推进信号（内部口径）
  - 成熟度判断：…（⚠️对外版剔除）
  ```

### S3 方案汇报 / 宣讲会
- **方法论**：决策导向 + 异议处理
- **抽取重点**：认可点、分歧、待澄清项、推进意向
- **专属模块模板**：
  ```markdown
  ### 达成的共识/认可点
  - …
  ### 分歧与待澄清
  | 议题 | 双方分歧 | 待澄清/待补充 |
  |---|---|---|
  ### 推进意向（内部口径）
  - …（⚠️对外版软化）
  ```

### S4 商务谈判 / 报价会
- **方法论**：立场-利益(BATNA) + 让步记录
- **抽取重点**：双方立场、真实利益、已让步项、未决条款、底线红线
- **专属模块模板**：
  ```markdown
  ### 谈判要点
  | 议题 | 对方立场 | 对方真实利益(研判) | 我方立场 |
  |---|---|---|---|
  ### 让步与未决条款
  - 已让步：…
  - 未决/挂起条款：…
  - 我方底线红线：…（⚠️强内部敏感，对外版必删）
  ```

### S5 POC 启动 / 复盘会
- **方法论**：目标-指标(SMART) + RAID
- **抽取重点**：验收标准、测试范围、结果、风险、Go/No-Go
- **专属模块模板**：
  ```markdown
  ### POC 范围与验收标准
  | 验收指标 | 目标值 | 负责人 | 期限 |
  |---|---|---|---|
  ### 结果与风险(RAID)
  - Risks(风险)：… | Assumptions(假设)：…
  - Issues(问题)：… | Dependencies(依赖)：…
  ### 结论
  - Go / No-Go / 待定：…
  ```

### S6 项目对齐 / 交付实施会
- **方法论**：3W + RAID
- **抽取重点**：进度、分工、卡点、依赖、时间线
- **专属模块模板**：
  ```markdown
  ### 进度与分工
  | 工作项 | 负责人 | 状态 | 截止 |
  |---|---|---|---|
  ### 卡点与依赖(RAID)
  - 卡点(Issues)：… | 依赖(Dependencies)：…
  - 风险(Risks)：… | 假设(Assumptions)：…
  ```

### S7 客户会销 / 沙龙 / 闭门会
- **方法论**：意向分级 + 跟进触发
- **抽取重点**：参会意向、关键互动、分级跟进动作
- **专属模块模板**：
  ```markdown
  ### 参会意向分级（内部口径）
  | 参会人/公司 | 关键互动信号 | 意向等级(A/B/C) | 触发的跟进动作 |
  |---|---|---|---|
  > ⚠️ 意向分级与研判为内部信息，对外版整块剔除。
  ```

### S8 内部销售复盘 / 战报会
- **方法论**：复盘四步（目标-结果-差距-改进）
- **抽取重点**：目标 vs 结果、差距归因、改进项、策略调整
- **专属模块模板**：
  ```markdown
  ### 复盘四步
  | 维度 | 内容 |
  |---|---|
  | 目标 | … |
  | 实际结果 | … |
  | 差距与归因 | … |
  | 改进项/策略调整 | … |
  > 纯内部场景，一般不产出对外版。
  ```

## B 类：通用企业会议

### G1 决策会
- **方法论**：Decision-Oriented + DACI
- **专属模块**：决议 + 决策依据 + 权责角色（Driver/Approver/Contributor/Informed）
  ```markdown
  ### 决议

  ```

  - …

  |---|---|

### G8 治理 / 正式会
- **方法论**：Robert's Rules of Order（议事规则）
- **专属模块**：
  ```markdown

  ```

### G9 通用兜底
- **方法论**：Action-Oriented 基础版
- **专属模块**：仅公共底座（摘要 + 决议 + 待办 3W），不加专属模块。

## 模块权重调节规则（对应三问的【问2】）

用户在【问2】勾选的侧重项，用于调整上述模块的详略：

| 用户勾选 | 加重的模块 |
|---|---|
| 客户真实痛点和需求 | S1 需求/痛点、S2/S3 反馈 |
| 决策链和预算信号 | S1 MEDDIC 表 |
| 客户的顾虑/异议 | S2/S3 异议跟踪表 |
| 明确的待办和责任人 | 公共底座待办 3W 表（所有 preset） |
| 谈判条款和让步记录 | S4 让步/未决条款 |
| 下一步跟进动作 | S7 跟进动作 / 各 preset 的"后续动作" |

未勾选的模块仍保留但简写，不删除结构。
